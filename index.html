Help & Feedback

How to Spin

Click on the wheel or press Ctrl + Enter to spin.

Edit Options

Type one name per line. Wheel updates automatically.

Add Multiple Wheels

Click "Add wheel" to create additional wheels.

Remove vs Continue

Remove: Winner removed from wheel.
Continue: Winner stays.

Shuffle & Sort

Randomize or alphabetize your options.

Change Theme

Go to Preferences → Theme for new wheels.

Dark Mode

Go to Preferences → Color scheme.

Keyboard Shortcuts

Ctrl + Enter — Spin the wheel

Mobile Usage

Tap the hamburger menu for all features.

Save & Open Wheels

Save: Export wheel as .wheel file.
Open: Import .wheel file from device.
New: Create a fresh wheel.

Share Wheels

Share: Generate a link with your wheel data. Anyone who opens the link will see the same wheel. Perfect for sharing with friends!

Make decisions fun and fair!

MySpinner is a beautiful, interactive wheel spinner that helps you make random decisions with style. Perfect for choosing meals, picking winners, or letting fate decide!

Interactive spinning wheel with smooth animations
Create unlimited wheels at once
7 beautiful color themes to choose from
Light, Dark, and System color modes
Save & load wheels as .wheel files

Realistic tick sounds while spinning
Fully responsive for mobile & desktop
